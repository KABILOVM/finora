# Finora — персональные финансы PWA

Прототип персонального учёта финансов с адаптивным интерфейсом, офлайн-режимом, кошельками, расходами/доходами/переводами, бюджетами, аналитикой, темами, экспортом и импортом JSON.

## Запуск
Для локального просмотра можно открыть `index.html`. Для проверки PWA и Service Worker нужен HTTPS или локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Открой `http://localhost:8080`.

## Дизайн
Стеклянный интерфейс (glassmorphism) в сине-фиолетовой гамме, светлая и тёмная темы, анимации с учётом `prefers-reduced-motion`. На телефоне: свайп влево по операции удаляет её (с кнопкой «Отменить»), панель добавления закрывается жестом вниз. Иконки Solar (CC BY 4.0) и Lucide (ISC) вшиты в `icons.js`, шрифт Manrope (SIL OFL) лежит в `fonts/`; всё работает офлайн. Знаки банков Алиф, Душанбе Сити и Хумо — упрощённые рисунки (Алиф по присланному логотипу) в приблизительных цветах (`BANKS` в `app.js`, символы `bank-*` в `icons.js`), не официальные логотипы.

## Вход и регистрация
Если Supabase настроен, при первом запуске показывается экран «Вход / Регистрация» (есть выход «Без аккаунта»). Сессию помнит Supabase, поэтому при следующих запусках приложение входит само, а в офлайне открывается с локальными данными. После входа данные берутся из облака, а если там пусто, туда уходят локальные. Перед заменой локальных данных облачными копия сохраняется в `localStorage['finora-local-backup']`.

## Облако
Интеграция с Supabase предусмотрена, но требует настройки своего проекта:
1. Выполни `supabase-schema.sql` в Supabase SQL Editor.
2. Заполни `supabase-config.js` публичным Project URL и publishable/anon key.
3. Размести файлы на HTTPS-хостинге.
4. В приложении открой «Настройки» и создай аккаунт/выполни вход.

Подробные шаги: `DEPLOY.md`. Спецификация продукта: `TECHNICAL_SPEC.md`. Разбор входа, сессий и рисков: `AUTHENTICATION_REVIEW.md`.

## Безопасность
Не помещай в `supabase-config.js` ключ `service_role` или другой секретный ключ. В браузере разрешён только публичный ключ Supabase при включённой RLS. Перед использованием с реальными финансовыми данными сначала настрой резервное копирование и проверь балансы. Курсы валют в прототипе демонстрационные.
