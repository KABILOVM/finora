# Иллюстрации: Fluent Emoji Flat

Цветные плоские рисунки из набора Fluent Emoji Flat (Microsoft, лицензия **MIT**, текст в `LICENSE-Fluent-Emoji-MIT.txt`). Скачаны через
[Iconify](https://iconify.design) как SVG (`https://api.iconify.design/fluent-emoji-flat/<имя>.svg`). Это настоящая векторная графика: масштабируется без потерь.

| Файл | Где используется |
| --- | --- |
| `soccer-ball` | «Футбол»: значок и картинка на карточке «Всего» |
| `sun-with-face` | «Аргентина»: картинка на карточке («Солнце мая» с флага) |
| `collision` | «Герой»: значок и картинка |
| `cat-face` | «Кавай»: значок и картинка |
| `rose` | «Эстетика»: значок и картинка |
| `racing-car`, `chequered-flag` | «Гонки»: картинка (болид на фоне флагов) и значок (флаг) |
| `robot` | «Киберпанк»: картинка |
| `cityscape-at-dusk` | «Киберпанк»: значок |
| `alien-monster` | «Пиксель»: значок и картинка |
| `snow-capped-mountain` | «Памир»: значок |

Рисуются в PNG скриптом `scripts/skin-art/rasterize.cjs`, дальше их превращает в webp `scripts/skin-art/build.py` (см. `../art/README.md`).
