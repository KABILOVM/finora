# Фотографии для образов «Таджикистан» и «Памир»

Из них `scripts/skin-art/build.py` делает фон карточки «Всего»: окрашивает фото в цвета образа по яркости (карта градиента) и ограничивает яркость.
Оба снимка с Wikimedia Commons, лицензия **CC BY-SA 4.0**: нужно указывать автора, а изменённый файл (webp в `../../art`) распространять на тех же условиях.
