# Образ «Паутина»: материалы

Заготовки для будущего образа «Паутина» (ночной фон, красное переходит в синее, паутина в углах, растр, взрывные подписи). Макет образа есть на странице «Образы Finora». В сборку эти файлы **не попадают**, пока на них нет ссылок из `src/`.

## Своё (`svg/`)

Нарисовано для Finora. Паутина считается по формуле: радиальные нити и провисающие между ними кольца.

| Файл | Что это |
| --- | --- |
| `web`, `web-corner`, `spider`, `thread`, `mask`, `eyes`, `sense`, `thwip`, `city` (`.svg`) | 9 значков 24×24, штрих `currentColor` толщиной 2, как у Lucide: паутина, паутина в углу, паук, паук на нити, маска, глаза маски, паучье чутьё (лучи вокруг головы), выстрел паутиной, город |
| `mask-color.svg` | Маска в цвете: красная, с паутиной и белыми глазами |
| `emblem.svg`, `emblem-light.svg` | Паук с красным брюшком: тёмный для светлых фонов и светлый для тёмных |
| `web-corner-tr.svg` | Светлая паутина с центром в правом верхнем углу, для карточки «Всего» |
| `pattern-tile.svg`, `pattern-tile-dim.svg` | Бесшовная плитка 340×260 из пяти паутин. Паутины целиком внутри плитки, поэтому при повторе ничего не режется. `-dim` — то же, но почти прозрачное, это фон образа |
| `sprite.svg` | Все значки как `<symbol id="spider-…">` |
| `preview.html` | Посмотреть всё в браузере |

## Палитра образа

| Цвет | Код |
| --- | --- |
| Ночь (фон) | `#0a0d1c` |
| Панель | `#121730` |
| Красный | `#e5232b` |
| Синий | `#1f4fb8` |
| Паутина | `#f4f4f8` |
| Доход | `#4ade80` |
| Расход | `#ff8d93` (светлее красного образа, чтобы не путать с акцентом) |

Контраст: белый текст на красном `#e5232b` даёт около 4,6:1, это нормально. Красный текст на фоне `#0a0d1c` даёт около 4,2:1, этого мало для мелкого шрифта, для красного текста брать светлее (например `#ff5a60`). Красным красим рамки и кнопки.

Шрифты: Oswald (заголовки и суммы), Nunito (текст), Kablammo для коротких взрывных подписей вроде «Твип!». У всех трёх есть все таджикские буквы.

## Права

Всё, кроме `svg/` (кроме `third-party/`), это чужие фан-материалы без лицензии или с ограничениями, образ и символ принадлежат правообладателям «Человека-паука». Файлы лежат здесь для личного некоммерческого использования владельца репозитория, их не стоит распространять. Если образ попадёт на публичный адрес, они будут отдаваться всем по ссылке. Паутина и паук в `svg/` нарисованы заново, но повторяют узнаваемые мотивы, так что к ним то же самое.

## Как пользоваться

- Плитка на фон: `background: #0a0d1c url('./svg/pattern-tile-dim.svg'); background-size: 340px 260px;`.
- Пиксельные спрайты показывать целым масштабом: `image-rendering: pixelated`.
- Значки красятся обычным `color`. Для вставки на страницу удобен `sprite.svg`: после встраивания `<svg width="24" height="24"><use href="#spider-mask" /></svg>`.
- CSP приложения (`img-src 'self' data: blob:`) пропускает эти файлы, если они лежат в сборке. Внешние адреса запрещены.
