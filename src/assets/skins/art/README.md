# Картинки образов в приложении

Готовые файлы, которые попадают в сборку и показываются в приложении. Их делает `scripts/skin-art/build.py` из «сырья» в соседних папках
(`../akatsuki`, `../barca`, `../real-madrid`, `../shinobi`, `../spider`, `../tajik`, `../football`). Вручную тут ничего не правят: поменяйте
скрипт и запустите его заново.

```sh
node scripts/skin-art/rasterize.cjs /tmp/skin-art   # гербы и флаг из SVG в прозрачные PNG (нужен Chromium: CHROMIUM_PATH=…, если версия Playwright не совпадает)
python3 scripts/skin-art/build.py /tmp/skin-art     # нужны Pillow и numpy
```

| Файл | Размер | Где показан | Из чего |
| --- | --- | --- | --- |
| `<образ>-hero.webp` | 640×320 | фон карточки «Всего» на главной (`--skin-art` в `src/index.css`) | см. ниже: у каждого образа своё |
| `<образ>-mark.webp` | 256×256 | водяной знак в углу карточки (`--skin-mark`): только `barca`, `real` | `barca`: logo/FC-Barcelona.svg; `real`: logo/Real-Madrid-CF.svg |
| `<образ>-thumb.webp` | 112×112 | значок образа в «Настройки → Оформление» (`src/skinThumbs.ts`), есть у всех 19 образов | кадр из фото или арта образа; у клубов герб, у «Шиноби» лицо Наруто (PNG), у «Классики» значок приложения |

### Картинка на карточке «Всего» (`-hero`)

## Как картинка не мешает тексту

Поверх карточки лежит белый текст, а цвета карточки подобраны так, чтобы он читался (контраст не меньше 4,5, это проверяет `src/accents.test.ts`).
Поэтому скрипт делает с каждой картинкой два шага:
1. **Левая часть уходит в прозрачность**, под ней обычный цвет карточки (для вырезанных героев весь холст прозрачный, кроме самой фигуры).
2. **Яркость каждой точки ограничена** (у вырезов этого нет: они стоят в углу, где текста нет) (`LCAP`, мягким «коленом»: тёмное почти не меняется, светлое прижимается к пределу). Смесь двух цветов не ярче, чем смесь их яркостей, поэтому белый текст читается поверх любой точки картинки.

## Что не попадает в офлайн-кэш

webp и jpg нет в `globPatterns` у `vite.config.ts`, а `assetsInlineLimit` не даёт встроить webp в код, поэтому каждая картинка отдельный файл и скачивается только тем, кто выбрал образ. Без сети остаётся обычный цвет карточки. Тест `src/skinArt.test.ts` следит за этим.

## Права

Это материалы без явной лицензии, найденные в сети: арты по «Наруто», «Акацуки» и «Человеку-пауку», гербы клубов. Фото из `photos/` с Unsplash свободны для использования, фото с Wikimedia Commons под CC BY-SA (авторы в `../photos/README.md` и `../tajik/photos/README.md`). Права на героев, символы и товарные знаки принадлежат правообладателям. В публичную сборку они положены по решению владельца репозитория (личное, некоммерческое приложение), и теперь отдаются любому, кто откроет адрес картинки. Убрать картинку образа можно, удалив строки `--skin-art` и `--skin-mark` из его блока в `src/index.css`; значок в настройках берётся из `src/skinThumbs.ts`.
