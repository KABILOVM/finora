# Brag Plan: Finora

## What is this app?
Finora — личный учёт денег (PWA): кошельки в разных валютах, расходы за три касания, бюджеты с ответом «сколько можно тратить в день», работает без интернета.

## The angle
Вопрос, который задаёт себе каждый в конце месяца: «Куда ушла зарплата?» — и Finora отвечает одной цифрой: сколько можно тратить сегодня.

## Hook (0–3.5s)
«Куда ушла зарплата?» крупно, затем «Finora знает.»

## Key moments
- Расход записывается за три касания: «+» → «Еда» → «Сохранить» (симуляция набора суммы 45,5).
- Экран бюджетов: «Осталось на день ≈ 796,76 с.».
- Кошельки, долги, регулярные платежи, импорт из Zenmoney — по одному.

## Outro / punchline
«Работает без интернета. Данные — только ваши.» + логотип FINORA.

## User flow worth showing
Главная (итог, график за 14 дней) → «+» → сумма и категория «Еда» → список операций → бюджет «Осталось на день».

## Tone
- Preset: app-store
- Creative direction: спокойный премиальный финансовый продукт, без крика
- Interpretation: чистые карточки, плавные выезды, один акцент на цифре «796,76 с.».

## Format: vertical — 1080x1920
## Duration: 21s

## Visual identity (из src/index.css, tailwind.config.js)
- Background: #080a18 (dark bg), светлое «стекло» #eceefb
- Accent: #4f46e5 (brand), #9061f9 (accent)
- Text: #eef0ff
- Display/Body font: Manrope (вшит в приложение)
- Strongest visual element: фиолетовая hero-карточка «Всего» и стеклянный интерфейс

## Share copy (draft)
Finora — учёт денег, который работает без интернета и сразу говорит, сколько можно тратить сегодня.

## Data note
Все суммы и названия на скриншотах — вымышленные демо-данные, снятые в локальном режиме без входа.

## Audio direction
- Role: warm bed + sparse UI accents
- Music: happy-beats-business-moves-vol-1 (120 BPM), fade in/out
- Music cue guidance: beat grid 0.5s; крупные появления на целых секундах
- Audio-reactive treatment: none (restraint)
- SFX posture: sparse, motion-matched (tick при вводе, drop при карточках, bong на логотипе)
- Restraint rule: музыка тише SFX и титров

## Storyboard
### Scene 1 — Hook — 3.5s
«Куда ушла зарплата?» (hold ≥1.5s), затем «Finora знает.»
### Scene 2 — Reveal — 3.5s
Телефон с «Главной» выезжает снизу; подпись «Личный учёт денег».
### Scene 3 — Flow — 5s
Экран «Новая операция», цифры набираются 4 → 45,5, выбирается «Еда»; затем список операций. Подпись «Расход — за три касания».
### Scene 4 — Daily budget — 4s
Экран бюджетов, подсветка «Осталось на день ≈ 796,76 с.». Подпись «Сколько можно тратить в день».
### Scene 5 — Chips — 2.5s
Три чипа по одному: «Кошельки в разных валютах», «Долги и платежи», «Импорт из Zenmoney».
### Scene 6 — Outro — 2.5s
«Работает без интернета.» + логотип + FINORA.
Music mood: calm upbeat. Audio summary: тёплая подложка, редкие щелчки интерфейса, колокольчик на логотипе.
