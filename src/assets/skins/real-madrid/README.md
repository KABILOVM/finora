# Образ «Реал Мадрид»: материалы

Заготовки для образа «Реал Мадрид»: белое и тёмно-синее, золото, корона. Макет и общий набор значков: `../football/`. В сборку эти файлы **не попадают**, пока на них нет ссылок из `src/`.

## Своё (`svg/`)

| Файл | Что это |
| --- | --- |
| `emblem.svg` | Герб по мотивам клубного: корона над щитом с синей наклонной полосой и золотой монограммой. Нарисован заново, это не официальный файл и не точная копия |
| `crown-color.svg` | Корона отдельно: золото, красные и белые камни |
| `crown-tile.svg`, `crown-tile-dim.svg` | Бесшовная плитка 240×200 из пяти корон (целиком внутри плитки). `-dim` — прозрачность 14%, фон образа |
| `lattice-tile.svg`, `lattice-tile-dim.svg` | Бесшовная плитка 64×64: ромбовая решётка, как стальной фасад «Бернабеу». Линии белые: годится на синем и тёмном фоне, на светлом не видно |
| `pinstripe-tile.svg` | Плитка 16×16: тонкая золотая полоска, как тканевый узор формы |
| `crown`, `crest`, `handkerchief`, `bernabeu` (`.svg`) | 4 значка 24×24, штрих `currentColor`: корона, щит с короной, белый платок «Hala Madrid», арка стадиона |
| `sprite.svg` | значки как `<symbol id="real-…">` |
| `preview.html` | посмотреть всё в браузере |

Общие значки (мяч, бутса, кубок и т. д.), разметка поля и флаг Испании лежат в `../football/`.

## Шрифты

Cormorant Garamond (SIL OFL): крупные заголовки и надписи на гербе-афише. Onest: суммы и мелкий текст (табличные цифры `tnum`). У обоих есть все таджикские буквы Ғ Қ Ҳ Ҷ Ӣ Ӯ (проверено в Chromium). Суммы набирать только Onest.

## Права

Картинки из `images/` — чужие фан-материалы без лицензии, герб и имена принадлежат клубу и правообладателям. Файлы для личного некоммерческого использования владельца репозитория, их не стоит распространять. `emblem.svg` нарисован заново, но повторяет известный герб, так что к нему то же самое.
