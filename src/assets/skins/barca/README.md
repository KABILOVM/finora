# Образ «Барселона»: материалы

> Часть файлов отсюда подключена к приложению (фон карточки «Всего», герб, миниатюра, значки образа), список и откуда что берётся — в `../art/README.md`. В сборку попадают только они и те, на которые есть ссылки из `src/`.

Заготовки для образа «Барселона»: сине-гранатовые полосы, золото, каталонский флаг, готовый логотип. Образ подключён в приложение (`src/index.css`, блоки `data-skin='barca'`, шрифт Montserrat из `../fonts`); из этой папки в сборку входит плитка `stripes-tile-dim.svg` (мяч на карточке «Всего» лежит в `../marks/ball.svg`). Логотипы из `logo/` и картинки из `images/` в приложение не подключены. Макет и общий набор значков: `../football/`. В сборку эти файлы **не попадают**, пока на них нет ссылок из `src/`.

## Своё (`svg/`)

| Файл | Что это |
| --- | --- |
| `stripes-tile.svg`, `stripes-tile-dim.svg` | Бесшовная плитка 96×96: четыре вертикальные полосы синий / гранатовый. `-dim` — то же с прозрачностью 16%, это и есть фон образа |
| `senyera-tile.svg`, `senyera-tile-dim.svg` | Бесшовная плитка 64×64: золотые и красные полосы (флаг Каталонии), второй файл с прозрачностью 12% |
| `crest`, `stripes`, `quatre-barres`, `visca` (`.svg`) | 4 значка 24×24, штрих `currentColor`: щит, полосы формы, четыре полосы Каталонии, шарф «Visca Barça» |
| `sprite.svg` | значки как `<symbol id="barca-…">` |
| `preview.html` | посмотреть всё в браузере |

Общие значки (мяч, бутса, кубок и т. д.), разметка поля и флаги Каталонии и Испании лежат в `../football/`.

## Готовые логотипы (`logo/`)

Не рисовал, а нашёл готовые SVG: [FCLOGO](https://github.com/FCLOGO/fclogo.top) (файлы `src/data/logos/RFEF/clubs/006_Barcelona/svg/`, версия «v2002»). Файлы лежат без изменений.

| Файл | Что это |
| --- | --- |
| `FC-Barcelona.svg` | герб в цвете, 800×800, 30 КБ |
| `FC-Barcelona-mono.svg` | одноцветный герб (чёрные части и белые) с серой отметкой источника, 28 КБ |

Особенность: у обоих файлов внизу (ниже 760 по оси y) маленькая серая подпись источника. На мелких размерах её не видно, на крупных можно обрезать `viewBox`. Источник сверялся с сайтом клуба (ссылка в метаданных репозитория).

## Шрифты

Montserrat (SIL OFL): заголовки, жирные начертания 700–900. Onest: суммы и текст (табличные цифры `tnum`). У обоих есть все таджикские буквы Ғ Қ Ҳ Ҷ Ӣ Ӯ (проверено в Chromium).

## Права

Картинки из `images/` — чужие фан-материалы без лицензии, герб и имена принадлежат клубу и правообладателям. Логотипы из `logo/` тоже его товарный знак: сайт-источник пишет, что права принадлежат владельцам, использование личное и некоммерческое. Всё это для личного некоммерческого использования владельца репозитория, не для распространения: если образ попадёт на публичный адрес, файлы будут отдаваться всем по ссылке.
