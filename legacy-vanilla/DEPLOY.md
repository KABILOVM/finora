# Развёртывание Finora бесплатно

## Что будет бесплатно
- Cloudflare Pages: хостинг статических файлов.
- Supabase Free: PostgreSQL и Auth в рамках текущих квот.
- PWA и локальное хранение: бесплатно.

Условия бесплатных тарифов могут меняться. На Supabase Free проекты могут приостанавливаться после периода неактивности; бесплатный тариф не заменяет независимую резервную копию.

## A. Настроить облачную БД
1. Открой https://supabase.com/dashboard и создай проект на Free.
2. Сохрани пароль базы в менеджере паролей; он не нужен для клиентского приложения.
3. В проекте открой **SQL Editor** и выполни содержимое `supabase-schema.sql`.
4. В **Project Settings → API** скопируй Project URL и publishable/anon public key.
5. В `supabase-config.js` замени `https://YOUR-PROJECT-REF.supabase.co` и `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` на реальные значения.
6. Не используй `service_role`/secret key во фронтенде. Таблица защищена RLS, пользователь может читать/менять только собственную запись.
7. В Supabase Auth проверь настройки подтверждения email. При включённом подтверждении пользователь должен подтвердить email перед первым входом.

## B. Разместить приложение на Cloudflare Pages
1. Распакуй ZIP.
2. Создай новый репозиторий GitHub и загрузи **содержимое папки** `finora-pwa-prototype` в корень репозитория.
3. Открой https://dash.cloudflare.com/ → **Workers & Pages** → **Create** → **Pages** → подключи GitHub-репозиторий.
4. Для простого статического сайта выбери Framework preset `None`; build command оставь пустой, output directory укажи `/` (или `.` — в зависимости от интерфейса настройки).
5. Нажми Deploy. Cloudflare выдаст адрес вида `https://имя-проекта.pages.dev`.
6. Открой ссылку, перейди в «Настройки», зарегистрируй аккаунт и проверь синхронизацию.

Если не хочешь использовать GitHub, можно развернуть статические файлы через доступный в панели Cloudflare способ загрузки; интерфейс и названия пунктов могут меняться.

## C. Установить на iPhone
1. Открой HTTPS-ссылку в Safari.
2. Нажми «Поделиться» → «На экран Домой».
3. Включи «Открывать как веб-приложение», если такой пункт отображается.

## D. Проверка облака
1. Создай аккаунт на устройстве A.
2. Нажми «Сохранить в облако».
3. Открой приложение на устройстве B, войди в тот же аккаунт и нажми «Загрузить из облака».
4. Убедись, что кошельки и операции появились.
5. Добавь запись и проверь, что после короткой задержки она синхронизировалась.

## Важные ограничения текущей версии
- Облачная синхронизация хранит единый JSON-снимок состояния пользователя. Для одного пользователя и небольшого объёма данных это простой старт, но одновременное редактирование на нескольких устройствах может приводить к конфликтам. Не редактируй данные одновременно на двух устройствах.
- Автосохранение в облако включается после входа. Первичную загрузку из облака выполняй вручную, чтобы случайно не затереть данные.
- Курсы валют демонстрационные; перед финансовым использованием необходимо подключить проверенный источник курсов и хранить исторический курс для каждой операции.
- Локальное хранилище пока использует `localStorage`, а не IndexedDB. Оно работает офлайн, но переход на IndexedDB остаётся задачей следующего релиза.
- Это не подключение к банковским API: операции вносятся вручную.
