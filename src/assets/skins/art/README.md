# Картинки образов в приложении

Готовые файлы, которые попадают в сборку и показываются в приложении. Их делает `scripts/skin-art/build.py` из «сырья» в соседних папках
(`../akatsuki`, `../barca`, `../real-madrid`, `../shinobi`, `../spider`, `../tajik`, `../football`). Вручную тут ничего не правят: поменяйте
скрипт и запустите его заново.

```sh
node scripts/skin-art/rasterize.cjs /tmp/skin-art   # гербы и флаг из SVG в прозрачные PNG (нужен Chromium: CHROMIUM_PATH=…, если версия Playwright не совпадает)
python3 scripts/skin-art/build.py /tmp/skin-art     # нужны Pillow и numpy
```

| Файл | Размер | Где показан | Из чего |
| --- | --- | --- | --- |
| `<образ>-hero.webp` | 640×320 | фон карточки «Всего» на главной (`--skin-art` в `src/index.css`) | `akatsuki`: banner-itachi-red; `spider`: hero-dynamic (вырезан по яркости); `shinobi`: art/naruto-pixel; `barca`: stadium-night; `real`: hala-madrid-pitch; `messi`: messi-10-art; `tajik`: bukhara-ikat-fabric; `pamir`: pamir-bulunkul-lake |
| `<образ>-mark.webp` | 256×256 | водяной знак в углу карточки (`--skin-mark`) | `barca`: logo/FC-Barcelona.svg; `real`: logo/Real-Madrid-CF.svg; `tajik`: emblem/emblem-1024.png |
| `<образ>-thumb.webp` | 112×112 | миниатюра в «Настройки → Оформление» (`src/skinThumbs.ts`) | то же, что выше, плюс флаг Испании, облако «Акацуки», голова Наруто, маска из `spider/images/hero-mask-closeup` |

## Как картинка не мешает тексту

Поверх карточки лежит белый текст, а цвета карточки подобраны так, чтобы он читался (контраст не меньше 4,5, это проверяет `src/accents.test.ts`).
Поэтому скрипт делает с каждой картинкой два шага:
1. **Левая часть уходит в прозрачность**, под ней обычный цвет карточки (для вырезанных героев весь холст прозрачный, кроме самой фигуры).
2. **Яркость каждой точки ограничена** (`LCAP`, мягким «коленом»: тёмное почти не меняется, светлое прижимается к пределу). Смесь двух цветов не ярче, чем смесь их яркостей, поэтому белый текст читается поверх любой точки картинки.

## Что не попадает в офлайн-кэш

webp и jpg нет в `globPatterns` у `vite.config.ts`, а `assetsInlineLimit` не даёт встроить webp в код, поэтому каждая картинка отдельный файл и скачивается только тем, кто выбрал образ. Без сети остаётся обычный цвет карточки. Тест `src/skinArt.test.ts` следит за этим.

## Права

Это материалы без явной лицензии, найденные в сети: арты по «Наруто», «Акацуки» и «Человеку-пауку», гербы клубов, фото. Права на героев, символы и товарные знаки принадлежат правообладателям. В публичную сборку они положены по решению владельца репозитория (личное, некоммерческое приложение), и теперь отдаются любому, кто откроет адрес картинки. Убрать их из приложения можно, удалив строки `--skin-art` и `--skin-mark` из блока образа в `src/index.css` и запись образа из `src/skinThumbs.ts`.
