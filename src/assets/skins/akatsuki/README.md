# Образ «Акацуки»: материалы

Заготовки для будущего образа «Акацуки» (чёрная ночь, красные облака с белой обводкой). Макет образа есть на странице «Образы Finora». В сборку эти файлы **не попадают**, пока на них нет ссылок из `src/`.

## Своё (`svg/`)

Нарисовано для Finora, облако обведено по мотивам картинки из `images/` и совпадает с ней по форме.

| Файл | Что это |
| --- | --- |
| `emblem.svg`, `emblem-dark.svg` | Облако целиком: красное `#e5121a` и тёмное `#7a1308`, белая обводка и три завитка |
| `pattern-tile.svg`, `pattern-tile-dim.svg` | Бесшовная плитка 340×260 из пяти облаков. Облака целиком внутри плитки, поэтому при повторе ничего не режется. `-dim` — то же с прозрачностью 16%, это и есть фон образа |
| `cloud`, `kasa`, `rinnegan`, `ring`, `mask`, `crow`, `moon`, `cloak` (`.svg`) | 8 значков 24×24, штрих `currentColor` толщиной 2, как у Lucide: облако, шляпа, ринеган, кольцо, маска, ворон, луна, плащ |
| `sprite.svg` | Все значки как `<symbol id="akatsuki-…">` |
| `preview.html` | Посмотреть всё в браузере |

Значок `cloud` на 24 px — упрощённое облако (два завитка из трёх), чтобы не сливалось. Цветное облако для крупных мест лучше брать из `emblem.svg`.

## Скачано (`images/`)

13 картинок с [wallpapers.com](https://wallpapers.com/akatsuki-symbol) (версия `hd`, размеры из названия страницы). На странице написано: бесплатно, но «для личного использования».

| Группа | Файлы |
| --- | --- |
| Одиночное облако на чёрном | `cloud-black` 1920×1080, `cloud-red-glow` 1920×1080, `cloud-dark-outline` 1920×1200 |
| Узоры из облаков | `pattern-dense` 1680×1050, `pattern-scatter` 1920×1080, `pattern-scatter-2` 1668×900, `pattern-grid` 1490×900, `pattern-grid-tall` 900×1212, `pattern-outline` 3000×1920 |
| Баннеры | `banner-wordmark` 1920×1200 (надпись AKATSUKI), `banner-dripping` 1989×1228 (стекающая краска), `banner-itachi-red` 1467×900, `banner-sharingan-cloud` 1920×1080 |

Для фона в приложении лучше своя плитка из `svg/`: она весит 4 КБ и не мылится на больших экранах. JPG годятся как референс и как картинки-баннеры для «О приложении».

## Палитра образа

| Цвет | Код |
| --- | --- |
| Ночь (фон) | `#0a0a0c` |
| Панель | `#14141a` |
| Красный | `#e5121a` |
| Тёмный красный | `#7a1308` |
| Мел (обводка, текст) | `#f6f6f6` |
| Доход | `#4ade80` |
| Расход | `#ff8585` (светлее красного образа, чтобы не путать с акцентом) |

Контраст: красный `#e5121a` на `#0a0a0c` даёт около 4,2:1, этого мало для мелкого текста. Красным красим рамки, кнопки (белый текст на нём даёт 4,7:1) и крупное. Для красного текста брать светлее, например `#ff4b4b` (6:1).

Шрифты: Oswald (заголовки и суммы, есть все таджикские буквы), Nunito (текст, тоже есть), Rubik Wet Paint только для слова «Finora» латиницей (в нём нет Ҳ ҳ).

## Права

Картинки из `images/` — чужие фан-материалы без лицензии, символ и облако принадлежат правообладателям «Наруто». Файлы здесь для личного некоммерческого использования владельца репозитория, их не стоит распространять. Если образ попадёт на публичный адрес, они будут отдаваться всем по ссылке. Материалы в `svg/` нарисованы заново, но облако повторяет известный символ, так что к ним то же самое.
