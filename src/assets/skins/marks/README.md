# Нейтральные украшения образов

Простые фигуры, нарисованные для Finora: белые, чтобы лежать на цветной карточке «Всего» полупрозрачным водяным знаком (`--skin-mark` в `src/index.css`).

| Файл | Где используется |
| --- | --- |
| `ball.svg` | «Барселона», «Испания», «Футбол» (мяч, штрих) |
| `sun.svg` | «Аргентина» (солнце с лучами) |
| `star.svg` | «Шиноби» (четырёхконечная звезда с отверстием) |
| `moon.svg` | «Акацуки» (полумесяц) |
| `burst.svg` | «Герой» (взрыв, как в комиксе) |
| `heart.svg` | «Кавай» (сердце) |
| `checker.svg` | «Гонки» (клетка) |

Здесь общие нейтральные фигуры (мяч, звезда, луна, сердце…) для образов, у которых нет своего герба или картинки. У «Шиноби», «Акацуки», «Паутины», «Барселоны», «Реал Мадрид», «Месси», «Таджикистана» и «Памира» на карточке «Всего» настоящие картинки из материалов (см. `../art/README.md`); у «Герой» и «Роналду» остались фигуры и цифры. Цифра «7» у «Роналду» — просто текст шрифтом образа.
